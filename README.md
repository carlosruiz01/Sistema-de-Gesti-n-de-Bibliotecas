# Sistema de Gestión de Biblioteca

Sistema de gestión de biblioteca desarrollado en Java utilizando Apache NetBeans, como proyecto integrador enfocado en la aplicación práctica del paradigma de Programación Orientada a Objetos (POO).
La aplicación permite administrar los libros de una biblioteca, consultar su disponibilidad, gestionar préstamos y devoluciones, así como controlar los usuarios y sus respectivos niveles de acceso.

El proyecto busca demostrar la aplicación de los principios fundamentales de la programación orientada a objetos, utilizando conceptos como composición, encapsulamiento, herencia, polimorfismo, interfaces y persistencia de objetos.

# Funcionalidades
- Gestión de libros
- Registrar libros dentro de la biblioteca.
- Retirar libros del inventario.
- Consultar información de los libros.
- Verificar la existencia de un libro.
- Consultar la disponibilidad de los libros.
- Controlar los préstamos y las devoluciones.
- Gestión de usuarios

El sistema cuenta con tres tipos de usuarios, cada uno con diferentes niveles de privilegios:

# Tipo de usuario	Privilegios
- Member:	Consultar libros y realizar préstamos.
- Admin:	Consultar libros, agregar y retirar libros, gestionar devoluciones.
- SuperAdmin:	Todos los privilegios de administración, incluyendo la gestión de administradores.

# Control de acceso
Autenticación de usuarios.

Identificación de los diferentes tipos de perfiles.

Restricción de operaciones según los privilegios de cada usuario.

Administración de usuarios y permisos.
